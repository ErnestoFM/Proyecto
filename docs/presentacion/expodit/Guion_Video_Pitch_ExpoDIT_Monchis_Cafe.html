BLOQUE 4: LA SOLUCIÓN Y SUS GENIALIDADES (1:20 - 1:55)

La primera es nuestra Resiliencia Transaccional con RabbitMQ y el Patrón Saga: si la red falla o el banco se interrumpe a media orden, el sistema compensa transacciones automáticamente y utiliza colas Dead Letter para garantizar cero pérdida de ventas ni cobros fantasma."

"La segunda genialidad es el motor Monchis Green Rewards: en tiempo real, el cajero activa el botón de termo reusable y el sistema premia al consumidor al instante. Todo operando sobre Google Cloud Run, una arquitectura Serverless que escala a cero costos cuando la cafetería está cerrada."
