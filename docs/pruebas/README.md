# Reportes de Pruebas y QA (`docs/pruebas/`)

Espacio para registrar casos de prueba, resultados de pruebas unitarias, integrales, de rendimiento y reportes de errores.

## 📄 Archivos Recomendados
- `plan-de-pruebas.md`: Estrategia de testing del proyecto.
- `reportes-ejecucion.md`: Bitácora de ejecución de suites de pruebas.
- `matriz-cobertura.md`: Cobertura de requerimientos vs casos probados.
