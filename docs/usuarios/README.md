# Documentación para Usuarios (`docs/usuarios/`)

Espacio para manuales de uso, guías visuales y documentación orientada a los usuarios finales o administradores del sistema.

## 📄 Manuales Operativos y Guías del Sistema

1. **[Manual de Usuario y Operación de Mostrador (POS)](file:///d:/ernestofm/Proyecto/docs/usuarios/manual-usuario.md):**
   - **Audiencia:** Cajeros de mostrador, personal de barra y atención al cliente.
   - **Contenido:** Operación del Punto de Venta, atajos de teclado (<kbd>F2</kbd>, <kbd>Escape</kbd>), escáner de código de barras USB/HID (1D/2D), métodos de pago (Efectivo, Tarjeta, Transferencia, Mixto), y programa de fidelización Monchis Rewards (7 sellos para 8vo café gratis y bonificación ecológica por termo).

2. **[Manual del Administrador de la Plataforma](file:///d:/ernestofm/Proyecto/docs/usuarios/manual-administrador.md):**
   - **Audiencia:** Administradores del sistema, gerencia de operaciones y personal de TI.
   - **Contenido:** Seguridad y Doble Factor de Autenticación (2FA / TOTP RFC 6238 con Google Authenticator / QR), KPIs de ventas en tiempo real, atribución de tráfico y campañas de marketing UTM (Google Maps vs Instagram), registro y trazabilidad de lotes de café orgánico, alertas automáticas por correo SMTP (caducidad, stock y DLQ), auditoría del Patrón Saga y exportación ejecutiva a Excel (UTF-8 BOM) y PDF.
