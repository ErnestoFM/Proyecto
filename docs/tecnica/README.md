# Documentación Técnica (`docs/tecnica/`)

Espacio dedicado a la arquitectura del sistema, APIs, esquemas de bases de datos y guías de desarrollo.

## 📄 Archivos Recomendados
- `arquitectura.md`: Diagramas y descripción de componentes del sistema.
- `api-spec.md`: Especificación de endpoints de API o contratos de servicio.
- `guia-instalacion.md`: Instrucciones paso a paso para desplegar en entorno local o producción.
