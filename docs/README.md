# Documentación del Proyecto (`docs/`)

Este directorio contiene la documentación oficial del proyecto categorizada según su propósito y audiencia objetivo.

## 📂 Subdirectorios

- **[`tecnica/`](file:///d:/ernestofm/Proyecto/docs/tecnica)**: Documentación técnica orientada a desarrolladores (Arquitectura, API Docs, Modelos de datos, Instalación y despliegue).
- **[`metodologia/`](file:///d:/ernestofm/Proyecto/docs/metodologia)**: Seguimiento de la metodología de trabajo (Sprints, Roadmap, Convenciones de código, Control de cambios).
- **[`pruebas/`](file:///d:/ernestofm/Proyecto/docs/pruebas)**: Reportes de pruebas, planes de QA, casos de prueba ejecutados y registro de bugs.
- **[`usuarios/`](file:///d:/ernestofm/Proyecto/docs/usuarios)**: Manuales de usuario final, guías de inicio rápido, tutoriales y preguntas frecuentes (FAQ).
