# Seguimiento de Metodología (`docs/metodologia/`)

Espacio para dar seguimiento al marco de trabajo (Scrum / Kanban), roadmap de entregas y decisiones del equipo.

## 📄 Archivos Recomendados
- `roadmap.md`: Plan de trabajo a corto, mediano y largo plazo.
- `convenciones.md`: Estándares de git, nombramiento de ramas y commits.
- `sprints.md`: Registro de reuniones, retrospectivas y compromisos de sprint.
