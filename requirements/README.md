# Requerimientos e Insumos del Proyecto (`requirements/`)

Esta carpeta está destinada a almacenar todos los insumos, documentos de negocio, especificaciones técnicas y requerimientos que se utilizarán para programar el proyecto.

## 📂 Organización de la Carpeta

- **`funcionales/`**: Historias de usuario, especificaciones funcionales, flujos de procesos, diagramas de caso de uso y reglas de negocio.
- **`tecnicos/`**: Especificaciones de API, arquitecturas requeridas, lista de dependencias, esquemas de bases de datos y requisitos previos de infraestructura.

## 📝 Instrucciones para el Usuario

1. Sube o arrastra aquí tus archivos de especificación (`.md`, `.pdf`, `.docx`, `.json`, etc.).
2. El agente de IA consultará esta carpeta para extraer el contexto necesario antes de proponer código o implementar funcionalidades.
