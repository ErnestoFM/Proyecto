# Bitácora de Trabajo — 2026-11-01

**Proyecto:** Monchis Café (Producción en Google Cloud Run)  
**Objetivo:** Rediseño integral de Contacto, Enlace de Clientes en POS, Historial de Compras y Facturación Digital Simplificada para Clientes, Expansión de Catálogo a 16 Productos de Especialidad y Optimización SEO Canónica.

---

## 📋 Resumen Ejecutivo de la Sesión

En esta sesión se atendieron todos los requerimientos solicitados para la experiencia de usuario y fidelización de Monchis Café:
1. **Página de Contacto (`/contacto`):** Incorporación de todos los canales de contacto directo (WhatsApp con enlaces dinámicos, teléfono, email, dirección física), formulario interactivo con selector de asunto y validación de privacidad, estatus en tiempo real de apertura/cierre de sucursal (`estadoHorario`), amenidades (Pet Friendly, WiFi 200Mbps, bicicletero seguro, Monchis Rewards +1 sello eco), mapa interactivo de Google Maps con accesos directos a Waze/Maps y botón interactivo "📋 Copiar Dirección" con toast, guía de transporte y cómo llegar, métodos de pago aceptados y orientación de facturación fiscal CFDI 4.0, redes sociales con enlace a Playlist oficial de Spotify Radio y acordeón interactivo de 5 preguntas frecuentes (FAQ), más botón flotante persistente de WhatsApp.
2. **Enlace Venta-Cliente y POS (`/pos`):** Incorporación del buscador reactivo de clientes por nombre y correo (`GET /api/pos/customers?q=...`) en el Punto de Venta. El cajero puede asociar la venta a un cliente registrado, ver sus puntos y sellos en tiempo real, redimir saldo de puntos como descuento directo ($1 MXN = 1 pt), y otorgar sellos y cashback automáticos con registro de `clienteId` en la orden.
3. **Historial de Compras y Facturas para el Cliente (`/dashboard`):** Creación del endpoint protegido `GET /api/orders/my-orders` y rediseño completo del Dashboard del Cliente con:
   - Tarjeta Digital de Miembro Monchis Rewards con código de barras escaneable, nivel de membresía (Grano Verde, Amante del Café, Maestro Caficultor) y cuadrícula visual de sellos.
   - Tabla responsiva de compras históricas con desglose de productos, método de pago, fecha y folio.
   - Modal de Comprobante Fiscal Digital Simplificado con datos fiscales de Monchis Café (`MCA260823-9K2`), desglose de IVA al 16%, sello digital, código QR SAT y botón nativo para imprimir / guardar en PDF.
4. **Catálogo de Especialidad:** Expansión del catálogo de 5 a 16 productos reales de café orgánico de altura (Chiapas y Oaxaca) y repostería artesanal, con órdenes históricas de muestra sembradas en PostgreSQL Cloud SQL.
5. **Optimización SEO y PWA:** Creación de `site.webmanifest`, actualización de `sitemap.xml` con URLs canónicas en Cloud Run y fecha actual (`2026-11-01`), `robots.txt` estructurado, y metadatos OpenGraph, Twitter Cards y Schema.org `CafeOrCoffeeShop` JSON-LD en `index.html`.
6. **Despliegue Multi-Contenedor en Google Cloud Run:** Ambas imágenes de contenedor (`monchis-api` y `monchis-web`) fueron compiladas exitosamente en Cloud Build y desplegadas en Cloud Run (`us-central1`), logrando 100% de tráfico activo.

## 💻 Comandos Ejecutados

```powershell
# 1. Verificación de compilación y suites de prueba
pnpm --filter api build
pnpm --filter web build
pnpm test

# 2. Compilación de imágenes en Google Cloud Build
gcloud builds submit --config=infra/gcp/cloudbuild-api.yaml . --project=monchis-cafe-prod
gcloud builds submit --config=infra/gcp/cloudbuild-web.yaml . --project=monchis-cafe-prod

# 3. Despliegue en Google Cloud Run
gcloud run deploy monchis-cafe-api --image=us-central1-docker.pkg.dev/monchis-cafe-prod/monchis-repo/monchis-api:latest --region=us-central1 --project=monchis-cafe-prod
gcloud run deploy monchis-cafe-web --image=us-central1-docker.pkg.dev/monchis-cafe-prod/monchis-repo/monchis-web:latest --region=us-central1 --project=monchis-cafe-prod
```
